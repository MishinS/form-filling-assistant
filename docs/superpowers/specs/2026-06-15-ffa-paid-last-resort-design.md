# FFA — Платный last-resort для LLM-цепочек (scan + extraction)

**Дата:** 2026-06-15
**Ветка:** `ffa-paid-last-resort` (от `main`@`2decc1d`)
**Тип:** надёжность / LLM-инфраструктура

## Проблема

Создание шаблона (`scan`) и заполнение шаблона (`extraction`) часто падают с
«Бесплатные модели сейчас перегружены» / «LLM недоступна». Root cause (подтверждён
прод-зондами 2026-06-13, см. memory): курируемый free-пул OpenRouter деградировал —
дефолт `gpt-oss-120b` перемежающе виснет/отдаёт мусор на реальных промптах,
`nex-n2-pro` стабильно виснет, qwen/llama хронический 429 (Venice сатурирован),
`openrouter/free` — рулетка. Последовательная цепочка с per-attempt таймаутами
выжигает 50-секундный бюджет на зависших моделях → `failure` → операция блокируется.
Чем крупнее загруженный шаблон/документ, тем вероятнее провал.

Free-пул принципиально ненадёжен (единственный free-хост многих моделей — Venice —
перманентно перегружен). Никакая перестановка free-моделей не делает фикс
дефинитивным.

## Решение (locked, подход C)

Добавить **одну платную модель** как **гарантированный last-resort** в ОБЕ цепочки.
Когда весь free-пул отбит/завис, платная модель отрабатывает за свой
зарезервированный отрезок времени — операция всегда завершается с реальным
результатом.

### Выбор модели

`google/gemini-2.5-flash-lite` (через OpenRouter, **платная**, не `:free`).

Почему она:
- Нативные structured outputs + сильная мультиязычность (русский) — именно там, где
  слабые free-модели отдавали мусор (`failure="nofields"`).
- Стабильный провайдер (Google), не подвержена Venice-сатурации free-пула.
- Быстрая (~1–2с), большой контекст.
- **Важно:** это платный Gemini через OpenRouter (биллинг через кредиты OpenRouter,
  прокси без регионального geoblock'а — прошлый провал прямого free-Gemini с
  `limit:0` в фазе 4 здесь не повторяется).

### Стоимость

Замер промптов из кода (русский ≈2.8 симв/токен):

| Операция | вход / выход (токены) | $/операция | на 1000 |
|---|---|---|---|
| Извлечение (заполнить шаблон) | ~4 750 / ~320 | ~$0.0006 | ~$0.60 |
| Скан (добавить шаблон) | ~4 300 / ~900 | ~$0.0008 | ~$0.79 |

Цена gemini-2.5-flash-lite на OpenRouter: $0.10/M вход, $0.40/M выход.
Баланс аккаунта на 2026-06-15: `total_credits 40`, `total_usage 33.93` → **~$6.07
остаток** (≈7 500 операций). Last-resort срабатывает редко (только при провале
free-пула) → реальные траты околонулевые. Аккаунт `is_free_tier:false` — платные
модели уже доступны, env-гейт не нужен.

## Архитектура (подход A)

Платная модель живёт **отдельной константой**, НЕ внутри `FREE_MODELS`. Это
сохраняет семантику free-каталога и его тесты («всё в списке = free»), а пикер и
обе цепочки явно дополняются платным пунктом.

### Каталог (`lib/extract/llm/catalog.ts`)

```ts
export const PAID_LAST_RESORT = {
  id: "google/gemini-2.5-flash-lite",
  name: "Gemini 2.5 Flash Lite (платная)",
  provider: "Google",
};

export function isPaidModel(id: string): boolean {
  return id === PAID_LAST_RESORT.id;
}
```

`FREE_MODELS` / `FREE_MODEL_IDS` / `DEFAULT_MODEL` НЕ меняются — дефолт остаётся
free `gpt-oss-120b`. `isFreeSlug` не трогаем (платный слаг → false, что корректно).

### Пикер (`ModelSelect`)

Показывает `[...FREE_MODELS, PAID_LAST_RESORT]`. Платный пункт визуально помечен
«(платная)» уже в `name`. Пользователь может выбрать его как primary (тогда каждая
операция платная — осознанный выбор).

### Цепочка извлечения (`lib/extract/llm/openrouter.ts`)

Строим единый список кандидатов так, чтобы платная **всегда присутствовала**:

```
candidates = dedupe([ selected, ...FREE_MODEL_IDS, PAID_LAST_RESORT.id ])
```

- Выбран free (обычный случай) → `[free-primary, ...остальные free, PAID-хвост]`.
- Выбрана платная явно → `[PAID, ...free]` (платная primary, free как нижний резерв).
- Неизвестный слаг из тела API (не из каталога) → `[slug, PAID-хвост]` (сохраняем
  degradation-поведение: не разворачиваем всю free-цепочку для произвольного слага,
  но платный хвост добавляем для надёжности).

Дедуп: `Array.from(new Set(...))` — сохраняет порядок, убирает дубль если
selected == PAID.

### Цепочка скана (`lib/templates/scan.ts`)

Скан **игнорирует** выбор пикера по дизайну (комментарий в коде). Платная — всегда
зарезервированный хвост, никогда не primary:

```
candidates = [ ...FREE_MODEL_IDS, PAID_LAST_RESORT.id ]
```

### Резервирование бюджета (крукс)

Текущее: `ATTEMPT_TIMEOUT_MS=30с` (extract) / `SCAN_ATTEMPT_TIMEOUT_MS=20с` (scan),
`CHAIN_DEADLINE_MS=50с`, route `maxDuration=60`.

Цель: платный хвост **гарантированно** получает ход, даже если free-модели зависли.

Новые константы (экспортируются из `openrouter.ts`, переиспользуются в `scan.ts`):
- `FREE_PHASE_DEADLINE_MS = 35_000` — free-кандидаты крутятся только до этой отметки.
- `PAID_TIMEOUT_MS = 12_000` — отрезок для платного хвоста.

Логика в цикле:
- Для **free-кандидата**: `remaining = FREE_PHASE_DEADLINE_MS − elapsed`; если ≤0 —
  переходим сразу к платному хвосту. Per-attempt таймаут =
  `min(ATTEMPT_TIMEOUT_MS, remaining)`.
- Для **платного хвоста** (последний кандидат, если он PAID и не был primary):
  таймаут = `min(PAID_TIMEOUT_MS, CHAIN_DEADLINE_MS − elapsed)`. Так он играет по
  своему отрезку, а не по исчерпанной free-фазе.
- Если платная — primary (выбрана явно, идёт первой): резервирование не применяется,
  она просто первый кандидат под обычным таймаутом.

Худший случай: free-фаза 35с + платный хвост 12с = 47с < 50с дедлайн < 60с
maxDuration → терминальный результат всегда успевает флашнуться, мёртвый экран
(`stream_empty` без retry) недостижим.

### Живой прогресс / ошибки

- `onAttempt({phase, model, index, total})` уже есть. `total` вырастет на 1 (платный
  хвост — лишний кандидат). Платная попытка покажет своё имя через резолв id→name
  (UI уже генеричен — новой логики не нужно).
- Если даже платная упала (сеть/баланс) → throw как у любой модели → существующая
  failure-панель с «Повторить». Новых кодов ошибок нет.
- `scan.ts`: мусор от платной → `failure="llm"`; валидный пустой → `nofields` — без
  изменений.

## Объём (файлы)

- `lib/extract/llm/catalog.ts` — `PAID_LAST_RESORT`, `isPaidModel`.
- `lib/extract/llm/openrouter.ts` — построение кандидатов с платным хвостом +
  reserved-бюджет; экспорт `FREE_PHASE_DEADLINE_MS`, `PAID_TIMEOUT_MS`.
- `lib/templates/scan.ts` — аппенд платного хвоста + reserved-бюджет (переиспользует
  экспортированные константы).
- `ModelSelect` (компонент пикера) — рендер `[...FREE_MODELS, PAID_LAST_RESORT]`
  (проверить, не итерирует ли он уже общий список — тогда правка минимальна).
- Тесты: catalog, openrouter, scan (см. ниже).

## Тестирование

- **catalog:** `PAID_LAST_RESORT` определён; `isPaidModel` true только для его id;
  `FREE_MODEL_IDS` НЕ содержит платный (free-чейн-семантика цела); существующий тест
  каталога не регрессирует.
- **openrouter:** (1) при выбранном free и исчерпании/провале free-фазы платный
  хвост ДОСТИГАЕТСЯ и возвращает результат; (2) платная выбрана primary → идёт
  первой; (3) дедуп: selected==PAID не даёт дубля; (4) платный хвост играет по
  `PAID_TIMEOUT_MS` даже когда free-фаза выжжена (fake-timers + abort-by-signal мок,
  как в существующих таймаут-тестах).
- **scan:** платный хвост всегда последний кандидат и достигается после free.

Ожидаемо: текущие 290 Vitest + ~6–8 новых (платный хвост / дедуп / бюджет /
catalog) → ~296–298. tsc / lint / `next build` зелёные; `pt.xlsx` остаётся в
`/api/fill` nft-трейсе.

## Вне скоупа

- Смена `DEFAULT_MODEL` (остаётся free gpt-oss).
- Денежные лимиты/гарды, авто-топап баланса.
- UAT на проде (owner-driven позже).
- Параллельная гонка моделей (подход B из дебага — отдельная возможная итерация).

## Открытые риски

- Баланс OpenRouter ~$6.07 — на текущих объёмах надолго, но при росте трафика и
  частых провалах free-пула может потребоваться топап. Не блокирует.
- Если OpenRouter сам поднимет цену gemini-flash-lite или выведет её — слаг в одной
  константе, замена тривиальна (как с free-каталогом).
